# CyberMesh React Web Application

## Responsibilities (Team Member 3)
- React 18, Vite, and Tailwind CSS dark cyber UI design system.
- Cytoscape.js interactive graph visualizer with zoom, pan, physics, and node inspection drawer.
- Real-time Recharts KPI telemetry dashboard.
- Complaint intake workflow with live "Analyze with AI" entity review dialog.
- Case details investigation dossier.

## How to Run
```bash
npm install
npm run dev      # Runs Vite dev server on http://localhost:5173
```

## How to Build
```bash
npm run build    # Produces production bundle in dist/
```
